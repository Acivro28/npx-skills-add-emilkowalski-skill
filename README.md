# Skills de animación e deseño para as webs de Luis Soto

Copia das skills de [Emil Kowalski](https://github.com/emilkowalski/skills) (licenza MIT, ver `LICENSE`) e unha skill propia, `webs-luis-soto`, que as resume e engade as convencións das webs de Luis Soto: Galicia XXI, Guláns, Acivro, SotoFlauta, Cecilia, bodas e Fisión.

## Contido

- `skills/webs-luis-soto/`: guía propia (castelán) para aplicar estes criterios a todas as webs.
- `skills/emil-design-eng/`, `animate/`, `review-animations/`, `improve-animations/`, `find-animation-opportunities/`, `animation-performance/`, `animation-vocabulary/`, `apple-design/`, `break-ui/`, `prototype/`, `pick-ui-library/`, `mobile-native/`, `animate-expo/`, `write-swift/`, `ask-sonner/`: skills orixinais de Emil Kowalski, sen cambios.
- `performance-cheatsheet.md`: resumo de rendemento de Emil Kowalski.

## Instalar

Nun asistente de programación compatible:

```bash
npx skills@latest add Acivro28/npx-skills-add-emilkowalski-skill
```

Ou só a orixinal:

```bash
npx skills@latest add emilkowalski/skills
```
